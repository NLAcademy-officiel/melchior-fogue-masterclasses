# Melchior Fogué — Masterclasses

Prototype statique indépendant.
- `index.html`: landing page animée et responsive, réservation simulée et espace vidéo.
- `melchior-fogue.webp`: photo originale fournie, copiée sans retouche.

**Attention :** formulaire de démonstration uniquement. Aucune donnée n'est enregistrée ou envoyée. Avant la mise en ligne, connecter une base de données/backend, une confirmation réelle et les automatisations.

Déployer uniquement depuis un nouveau dépôt, par exemple `melchior-fogue-masterclasses`. Ne pas modifier les dépôts NLAcademy ou NLAgent.
